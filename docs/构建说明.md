# 构建说明

## 环境

- Windows 10 / 11 x64
- Python 3.10+
- [PyInstaller](https://pyinstaller.org/) 6.x
- [Inno Setup](https://jrsoftware.org/isinfo.php) 6 / 7（仅生成安装包需要）

安装构建依赖：

```powershell
python -m pip install -r requirements-dev.txt
```

## 一键构建

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

脚本会：

1. 清理旧的 `packaging\dist`、`build`、`portable`、`installer`；
2. 用 PyInstaller 生成免安装目录 `packaging\dist\划词翻译\`；
3. 生成单文件便携版 `packaging\portable\划词翻译-便携版.exe`；
4. 调用 Inno Setup 的 `ISCC.exe` 生成 `packaging\installer\划词翻译-安装包.exe`；
5. 输出 SHA256。

如果 Inno Setup 不在默认路径，可以设置环境变量：

```powershell
$env:ISCC = "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

## 手动构建

### 1. 免安装目录

```powershell
python -m PyInstaller --noconfirm --clean --windowed `
  --name "划词翻译" `
  --icon "图标.ico" `
  --version-file "packaging\version_info.txt" `
  --add-data "图标.ico;." `
  --add-data "README.md;." `
  --distpath "packaging\dist" `
  --workpath "packaging\build" `
  --specpath "packaging" `
  "划词翻译.pyw"
```

### 2. 便携版

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name "划词翻译-便携版" `
  --icon "图标.ico" `
  --version-file "packaging\version_info.txt" `
  --add-data "图标.ico;." `
  --add-data "README.md;." `
  --distpath "packaging\portable" `
  --workpath "packaging\build_portable" `
  --specpath "packaging" `
  "划词翻译.pyw"
```

### 3. 安装包

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 7\ISCC.exe" "packaging\安装包.iss"
```

## 输出文件

```text
packaging/dist/划词翻译/划词翻译.exe
packaging/portable/划词翻译-便携版.exe
packaging/installer/划词翻译-安装包.exe
```

## 发布流程

1. 更新 `划词翻译.pyw` 里的 `VERSION`、`packaging/version_info.txt`、`packaging/安装包.iss` 和 `CHANGELOG.md`；
2. 运行构建；
3. 新建 GitHub Release，Tag 使用 `v1.2.0` 形式；
4. 上传安装包、便携版和 `SHA256SUMS.txt`；
5. 不要在 Git 中提交 exe、`dist/`、`build/` 或 `installer/`。

生成校验文件：

```powershell
Get-FileHash "packaging\installer\划词翻译-安装包.exe" -Algorithm SHA256
Get-FileHash "packaging\portable\划词翻译-便携版.exe" -Algorithm SHA256
```

## 注意

- `安装包.iss` 中所有路径均为相对路径，不要写死个人电脑目录；
- `图标.ico`、`README.md` 作为 data 打进 exe，运行时通过 `sys._MEIPASS` 读取；
- 用户数据写入 exe 所在目录，因此安装包默认安装到 `%LOCALAPPDATA%`，不要安装到 Program Files；
- PyInstaller 产物可能被部分杀毒软件误报，发布前建议在干净 Windows 虚拟机测试。
