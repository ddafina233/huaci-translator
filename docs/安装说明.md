# 安装与使用说明

## 系统要求

- Windows 10 / Windows 11，64 位；
- 发布版不需要安装 Python；
- 需要能访问腾讯翻译 / 有道词典（或其降级接口）。

## 下载哪个文件

在 GitHub 仓库的 **Releases** 页面下载：

| 文件 | 用途 |
| --- | --- |
| `划词翻译-安装包.exe` | 推荐。安装到当前用户目录，创建开始菜单快捷方式和卸载程序 |
| `划词翻译-便携版.exe` | 免安装。单文件直接运行，配置和生词本保存在 exe 所在目录 |

安装包是 x64 程序，不支持 32 位 Windows 或 ARM64 Windows。

> 安装包未做代码签名，Windows SmartScreen 可能显示「未知发布者」。点「更多信息」→「仍要运行」即可。

## 安装版

1. 双击 `划词翻译-安装包.exe`；
2. 按向导完成安装，可勾选「创建桌面快捷方式」；
3. 安装完成后从开始菜单或桌面启动「划词翻译」。

默认安装目录：

```text
%LOCALAPPDATA%\Programs\划词翻译
```

安装到当前用户目录，不需要管理员权限。

卸载：

- 开始菜单 → 划词翻译 → 卸载划词翻译；或
- Windows 设置 → 应用 → 已安装的应用 → 划词翻译。

卸载时会先结束正在运行的划词翻译。用户数据（生词本、设置、缓存、日志）默认保留在安装目录，避免误删生词；确认不需要后可手动删除该目录。

## 便携版

把 `划词翻译-便携版.exe` 放到一个有写入权限的文件夹（例如 `D:\Tools\划词翻译\`），双击运行。

程序会在 exe 所在目录生成：

- `生词本.json`
- `设置.json`
- `翻译缓存.json`
- `运行日志.log`

不要放在 `C:\Program Files` 等只读目录，否则无法保存生词本。

## 首次启动

- 首次运行会显示欢迎窗口；
- 屏幕右侧会出现「译」悬浮球；
- 如果悬浮球被隐藏：按 `Alt+W` 打开生词本 → 右上角「设置」→ 打开「显示桌面悬浮球」。

## 使用

1. 在浏览器、Word、PDF 阅读器、微信等软件中拖选文字；
2. 松开鼠标，先出现紧凑译文；
3. 鼠标移到弹窗上展开完整词性、短语、例句和操作按钮，移开自动收起；
4. 点「＋ 生词本」收藏，或点「网页搜索」查更多资料。

| 快捷键 | 作用 |
| --- | --- |
| `Alt+Q` | 翻译当前选中文字 |
| `Alt+W` | 打开生词本 |
| `Esc` | 关闭翻译弹窗 |

如果快捷键冲突，程序会自动降级到 `Ctrl+Alt+Q` / `Ctrl+Alt+W`，实际键位显示在设置窗口。

## 把旧电脑的生词本迁移到新电脑

1. 在新电脑上安装并启动一次划词翻译，然后退出；
2. 打开新电脑的安装目录（默认 `%LOCALAPPDATA%\Programs\划词翻译`）；
3. 把旧电脑的 `生词本.json` 复制进去，覆盖同名文件；
4. 重新启动程序。

便携版同理：把 `生词本.json` 放到便携版 exe 旁边。

## 常见问题

### 选中文字后没有弹窗

- 确认程序正在运行（看任务管理器或悬浮球）；
- 确认没有在悬浮球菜单里「暂停划词」；
- 某些管理员权限窗口不接受普通程序的模拟复制，可以先手动 `Ctrl+C`，再按 `Alt+Q`；
- 扫描版 PDF / 图片没有文本层，无法直接划词。

### 翻译失败

检查网络；腾讯/有道接口偶尔会限流。稍等几秒点「重试」，或直接用「网页搜索」。已经翻译过的内容仍会从本地缓存秒出。

### 想关闭程序

右键悬浮球 → 退出。如果悬浮球被隐藏，先按 `Alt+W` 打开生词本 → 设置 → 重新显示悬浮球，再右键退出。

## 隐私

选中的文字会发送到腾讯翻译 / 有道词典的公开接口；生词本、设置、缓存和日志只保存在本机。详见 [PRIVACY.md](../PRIVACY.md)。
